# Simulador de tempo nas redes sociais

Página educativa que calcula o tempo informado pelo usuário em períodos de uma semana e de 30 dias, compara o uso diário com a média da atividade e apresenta uma reflexão.

## Arquivos

- `index.html`: estrutura da página.
- `style.css`: cores, layout e adaptação para celular.
- `script.js`: dados da atividade e cálculos.

## Como abrir

Baixe os arquivos e abra `index.html` em um navegador. O simulador não precisa de servidor nem de instalação.

## Publicar pelo GitHub Pages

1. Crie um repositório público chamado `simulador-redes-sociais`.
2. Envie `index.html`, `style.css`, `script.js` e este `README.md` para a raiz do repositório.
3. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`, depois salve.
4. Aguarde o GitHub Pages publicar e copie o link exibido na página de configurações.

Os números de referência e as mensagens são os dados simulados fornecidos no enunciado da atividade.
